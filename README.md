# Tip Calculator

Work out the tip, the total, and the per-person split for a bill. Runs entirely in your browser.

**Live:** <https://tip-calculator.slippylabs.com/>

## What it does

- Enter the bill, pick a tip percentage (10/15/18/20/25% presets or your own), and split it across the table.
- Tip, total and per-person share all update live as you type.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/tip-calculator.slippylabs.com.git
cd tip-calculator.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
